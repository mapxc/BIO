# Сайт-визитка (нуар) для GitHub Pages

Сайт только для просмотра. Входа, токенов и админ-панели нет: всё меняется через GitHub.

## Файлы
- `index.html`, `style.css`, `app.js` — сайт (трогать не нужно).
- `data.json` — весь контент: имя, подзаголовок, «О себе», соцсети, площадки.
- `resume.pdf` — резюме (положи рядом, имя файла должно быть именно такое).
- `.nojekyll` — необязательный служебный файл.

## Запуск
1. Создай публичный репозиторий `USERNAME.github.io` и загрузи все файлы (Add file → Upload files).
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Через 1–2 минуты сайт откроется на `https://USERNAME.github.io`.

## Как менять
- Контент: открой `data.json` → значок карандаша → правь → Commit changes.
- Резюме: Add file → Upload files → `resume.pdf` (заменит старый).
- В `data.json` уже есть примеры (LinkedIn, GitHub, Telegram, Email, TryHackMe, Hack The Box и другие). Замени `YOUR-NAME`, `YOUR-ID` и `example.com` на свои данные, ненужные блоки удали.
- Новый сайт/платформа: скопируй блок `{ "title": ..., "url": ..., "desc": ... }` в `links` (или в `socials` для соцсетей).
- Порядок плашек = порядок блоков в файле.
- Изменения видны примерно через минуту (обнови страницу Ctrl+F5).

## Языки
Переключатель RU / KY / EN / JA вверху страницы. Язык запоминается в браузере, при первом заходе берётся язык устройства (иначе английский).
Поля `name`, `tagline`, `about`, `desc` могут быть строкой (один текст для всех) или объектом
`{"ru": "...", "ky": "...", "en": "...", "ja": "..."}`. Если перевода нет, показывается английский, затем русский.

## Безопасность
- В коде нет токенов и входа, на странице нечего украсть и нечем управлять. Менять сайт может только тот, у кого есть доступ к репозиторию, это решает GitHub.
- Включи 2FA на GitHub-аккаунте.
- CSP разрешает только свои скрипты и стили, запросы только к своему сайту. Весь текст выводится безопасно, ссылки допускаются только `https:` и `mailto:`, внешние открываются с `noopener noreferrer`.
- Защита от встраивания в чужой iframe. GitHub Pages не даёт задавать HTTP-заголовки, поэтому CSP и эта защита сделаны через meta и JS.
- Не пиши в `data.json` ничего секретного: файл публичный.
