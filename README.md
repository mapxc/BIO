# Сайт-визитка (нуар) для GitHub Pages

Файлы: `index.html`, `style.css`, `app.js`, `data.json` (контент), `.nojekyll`.
Положи рядом свой `resume.pdf` (или загрузи его позже через админ-панель).

## Запуск
1. Создай репозиторий `USERNAME.github.io` (или любой другой) и залей все файлы.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Если сайт на своём домене, впиши `owner` и `repo` в `CFG` в начале `app.js`.

## Токен для админ-режима
1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate.
2. Repository access: **Only select repositories** → только этот репозиторий.
3. Permissions → Repository → **Contents: Read and write** (больше ничего).
4. Срок жизни: 30–90 дней.
5. На сайте: нажми ◼ в правом нижнем углу (или открой `/#admin`), вставь токен.

Изменения коммитятся в `data.json` и `resume.pdf`, Pages пересобирается за ~1 минуту.

## Модель безопасности
- Права на запись определяет GitHub, а не JavaScript. «Админ-режим» без токена владельца бесполезен: любой посетитель увидит только просмотр, а попытка записи вернёт 403.
- Токен никогда не хранится в репозитории. По умолчанию лежит в `sessionStorage` (до закрытия вкладки), «Запомнить» кладёт в `localStorage`.
- Вход проверяет: токен принадлежит владельцу и имеет право `push` на этот репозиторий.
- Автовыход через 20 минут бездействия.
- CSP запрещает сторонние скрипты, стили, шрифты и запросы (разрешён только `api.github.com`), что закрывает основной путь кражи токена через XSS.
- Весь пользовательский текст выводится через `textContent`; ссылки допускаются только `https:` и `mailto:` (нет `javascript:`); внешние ссылки с `noopener noreferrer`.
- Защита от встраивания в iframe (clickjacking), `referrer: no-referrer`.
- Перед сохранением проверяется SHA файла: чужие изменения не перезаписываются.
- PDF проверяется по размеру (≤5 МБ) и сигнатуре `%PDF-`.

## Что ещё сделать на GitHub
- Включи 2FA на аккаунте.
- Branch protection для `main` НЕ включай с обязательным PR, иначе запись по токену будет отклонена; либо используй отдельную ветку.
- Не давай токену права на другие репозитории.
- Если токен утёк: Settings → Developer settings → отзови токен.
- Ограничение: GitHub Pages не позволяет задавать HTTP-заголовки, поэтому CSP и защита от iframe реализованы через meta и JS.

## Языки
Переключатель RU / KY / EN / JA стоит в верху страницы. Язык запоминается в браузере, при первом заходе берётся язык браузера (иначе английский).
Интерфейс (заголовки, кнопки резюме) переведён во всех четырёх языках. Текстовые поля в `data.json` (`name`, `tagline`, `about`, `desc`) могут быть строкой (один текст для всех) или объектом `{"ru": "...", "ky": "...", "en": "...", "ja": "..."}`. В админ-режиме поля правятся для того языка, который сейчас выбран: переключи язык и впиши перевод. Если перевода нет, показывается английский, затем русский.
